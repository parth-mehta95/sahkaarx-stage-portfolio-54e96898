# Practice Conflict Resolution and PR Workflow

## Task Brief
Create feature branches, simulate merge conflicts, resolve them, and submit a pull request with proper documentation.

## Scenario
Your team is adding features in parallel. Create a feature branch, simulate a conflict, resolve it cleanly, and submit a PR.

## Deliverables
- Feature branch with commits
- Resolved merge conflict

## Success Criteria
- Feature branch created from develop
- Conflict resolved with clear commit message
